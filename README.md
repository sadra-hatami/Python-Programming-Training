# 📖 About

**Introduction to Python** is an educational repository with three interactive Jupyter notebooks that teach the core building blocks of Python.

The lessons start from the simplest ideas — numbers, strings, variables, and booleans — then move to lists, tuples, dictionaries, sets, and conditionals, and finish with writing reusable functions.

Each notebook includes short explanations, runnable examples, and practice exercises so you can learn by doing, not only by reading.

> **Tagline:** *A practical Python learning repository covering data types, data structures, and functions through interactive Jupyter Notebooks.*

# 📚 Lessons

| # | Notebook | Topics |
|---|----------|--------|
| 1 | [Lesson_1_Python_Data_Types.ipynb](Lesson_1_Python_Data_Types.ipynb) | Numbers, comments, strings, `print()`, variables, f-strings, booleans, comparison operators |
| 2 | [Lesson_2_Python_Data_Structures.ipynb](Lesson_2_Python_Data_Structures.ipynb) | Lists, tuples, if / elif / else, dictionaries, sets, loops, list comprehensions |
| 3 | [Lesson_3_Functions.ipynb](Lesson_3_Functions.ipynb) | Defining functions, parameters, `return` values, reusable code |

### Suggested order

1. Start with **Lesson 1** to understand values and variables.
2. Continue with **Lesson 2** to store and organize data.
3. Finish with **Lesson 3** to wrap logic inside functions.

# ▶️ How to Use

### Option 1 — Open on GitHub

1. Open this repository.
2. Click any `.ipynb` file.
3. Read the cells and review the examples.

### Option 2 — Run locally

```bash
git clone https://github.com/sadra-hatami/Introduction-Python.git
cd Introduction-Python
```

Then install Jupyter if needed:

```bash
pip install notebook
jupyter notebook
```

Open the lesson files one by one and run the cells.

### Option 3 — Google Colab

Upload any notebook to [Google Colab](https://colab.research.google.com/) and run it in the browser with no local setup.
