# 📖 درباره

**آموزش برنامه‌نویسی پایتون** یک مخزن آموزشی با سه نوت‌بوک تعاملی Jupyter است که پایه‌های پایتون را درس می‌دهد.

درس‌ها از ساده‌ترین ایده‌ها شروع می‌شوند: عدد، رشته، متغیر و بولین. بعد به لیست، تاپل، دیکشنری، مجموعه و شرط می‌رسند و با نوشتن تابع قابل استفاده تمام می‌شوند.

هر نوت‌بوک توضیح کوتاه، مثال اجرایی و تمرین دارد تا یادگیری با اجرا باشد، نه فقط با خواندن.

> **جمله کوتاه:** *مخزن عملی یادگیری پایتون که انواع داده، ساختار داده و تابع را با نوت‌بوک Jupyter پوشش می‌دهد.*

### راه ۲ — اجرای محلی

```bash
git clone https://github.com/sadra-hatami/Python-Programming-Training.git
cd Python-Programming-Training
```

اگر Jupyter نداری:

```bash
pip install notebook
jupyter notebook
```

فایل درس‌ها را یکی‌یکی باز کن و سلول‌ها را اجرا کن.
